# 画面模板（视频定格/过场画面体系）

常青藤篮球训练赛视频剪辑的**标准画面资产**，分「比赛版」（全场集锦过场体系）和「个人版」（球员集锦页面）两套。所有页面 9:16 竖版 1080×1920，配色统一深蓝紫渐变背景 + 活力橙强调（A队紫、B队橙）。

## 目录结构

```
画面模板/
├── README.md
├── 生成脚本/
│   ├── gen_pages_比赛版.py      # 比赛版生成器（12页）
│   └── gen_pages_个人版.py      # 个人版生成器（4页）
├── 比赛版/                       # 全场集锦：片头→每节过场→全场数据→趋势→片尾
│   ├── 01_片头/片头页            # 视频开始定格：LOGO + A/B队 + 最终比分占位
│   ├── 02_节数据过场/第1节~第8节  # 每节播放完的过场定格：本节比分核对 + 本节球队数据 + 本节高光
│   ├── 03_全场数据/全场数据页     # 最终比分 + 两队数据对比（得分/投篮/三分/罚篮/篮板/助攻/抢断/盖帽）+ 教练点评
│   ├── 04_趋势图/每节得分趋势     # 第1~8节 A/B队双色柱状得分曲线
│   └── 05_片尾/片尾页            # 视频结束定格：本场集锦完 + 最终比分核对
└── 个人版/                       # 球员集锦（示例=施柏宇，每场比赛每名球员一套）
    ├── 01_封面/封面页            # 球员名 + 本场得分 + 登记照占位(身高/体重/年龄) + 雷达图 + 教练点评
    ├── 02_节数据/节数据页         # 本节比分核对 + 本节个人数据(得分/篮板/助攻/抢断) + 本节高光
    ├── 03_汇总/汇总数据页         # 核心数据 + 投篮明细 + 每节得分趋势 + 6维雷达图 + 教练点评
    └── 04_封底/封底页            # 本场集锦完 + 比分核对
```

## 每场比赛怎么用

### 比赛版（全场集锦）
1. 拷贝 `比赛版\` 整个目录到比赛日文件夹（如 `01_比赛日\2026.xx.xx\04_画面模板\`）
2. 改 `生成脚本\gen_pages_比赛版.py` 顶部的 `G` 字典：日期、队名
3. 比赛数据统计完成后，把占位 `--` 替换为剪辑表真实数据（比分、两队数据、每节得分）
4. 运行脚本重新出图，把 PNG 按顺序插入视频：片头 → 第1节片段 → 第1节过场 → 第2节片段 → … → 第8节过场 → 趋势图 → 全场数据 → 片尾
5. 剪辑规范：过场定格画面在视频中停留 2~3 秒（可与 xfade 转场配合）

### 个人版（球员集锦）
1. 拷贝 `个人版\` 到球员文件夹
2. 改 `gen_pages_个人版.py` 里的 `P` 字典：球员名、队、日期、各项数据、雷达图基准、教练点评文案
3. 运行脚本，4 页 PNG 用于该球员集锦的片头/节过场/汇总/片尾
4. 登记照（身高/体重/年龄）待小程序球员档案数据接入后自动填充

## 配色规范（与共享资产\UI 配套）

| 用途 | 色值 |
|---|---|
| 背景渐变 | #101b33 → #16294d → #1b3564 |
| 强调橙（重点数值/高亮） | #ff8a3d / #ffb84d |
| A队（紫系） | #b8a8ff |
| B队（橙系） | #ffb84d |
| 次级文字 | #9fb4d8 / #6f85ab |
| 正文 | #ffffff / #e8eefb |

## 命名规范

- 比赛版：`第X节.png`、`片头页.png`、`全场数据页.png`、`每节得分趋势.png`、`片尾页.png`
- 个人版：`封面页.png`、`节数据页.png`、`汇总数据页.png`、`封底页.png`
- 成品视频文件名遵循《通用剪辑规范》：`球员名（数据统计）.mp4` / 比赛日集锦按节命名

## 数据来源

所有占位数据赛后从 `标准文档\01_比赛剪辑表\` 的剪辑表填充：
- 比分核对 ← 数据核对sheet（全场 vs 各节之和）
- 每节球队数据 ← 第X节 Stats
- 全场数据 ← Game Stats
- 每节得分趋势 ← 各节 Stats 的 V（得分）
- 个人数据/雷达图 ← Game Stats 该球员行 + 小程序档案

⚠️ 球员特点文案统一叫「教练点评」，禁止出现"AI 点评/AI 总结"字样。
