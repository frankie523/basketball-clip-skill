## 3. 第1步：录入素材

1. 多段录像命名 `{YYYYMMDD}_{序号}_{备注}.mp4` 放入 `00_原始素材\`
2. 多段合并为母带（**后续所有切割的唯一源，合成后不再改**）：
   ```
   ffmpeg -f concat -safe 0 -i list.txt -c copy 合成母带.mp4
   ```
   concat 前确认所有输入**同分辨率、同采样率（48k stereo）**，否则 -c copy 失败。

### 3.1 分节方法（白底比分帧，2026-10-23 沉淀）

母带每节结束若带**全屏白底比分画面**（写有「第X节 / A队 XX : B队 XX」），直接用播放器拖进度条找白底画面，记录每节结束的**母带时间+比分**，即可自动分出每节时间范围：

| 节次 | 母带时间 | 比分 |
|---|---|---|
| 第一节结束 | 00:04:08 | A20:B19 |
| 第二节结束 | 00:07:52 | A39:B40 |

- **分节时间一律用母带绝对时间**（不是各节自己的0秒），分节只是全场的拆分
- 接力赛和对抗赛的分节点都要以实际比赛顺序为准，**不能按文件名排序或拼接顺序推断**

## 4. 第2步：生成比赛剪辑表（最易出错，权重最高）

### 4.1 抽字幕帧 + OCR
- **必须用 2fps**：`脚本库\ocr\batch_ocr2.ps1`（底部字幕区 crop=1920:160:0:920 → OCR → `ocr2_full.csv`）
- 1fps 会把字幕完整窗口压短、切断事件，禁止用于正式解析
- 字幕物理格式（已封版）：**「人名+（数据统计）」**，括号内全部动作归括号前人名；出现新「人名+（」即切换归属

### 4.2 解析事件
- `parse_1004_2fps.py` → `parsed_*.json`（含 **start_s/end_s 真实字幕完整窗口** + acts）
- 连续帧合并：动作子集相同 **或 文本相似度 ≥0.85** 才合并；**文本变化导致"球员集合变化"必须断窗**（防两条无缝字幕被合并，10.04 c14 教训）
- 别名归一（雷→雷奕梵、誆投→近投 等）按《数据字典》映射表
- 同一 (start,end,player) 的重复事件 → 按动作次数合并去重

### 4.3 统计口径铁律（违反即返工）

| 规则 | 内容 |
|---|---|
| 得分 | **只认字幕「得分+N」的 N**；投篮动作只计出手次数，严禁把投篮次数当得分 |
| 命中 | 投篮子句后**紧邻**「得分+N」（中间无篮板/盖帽/人名切换）→ 该投篮命中，得分归投篮者 |
| 失手 | 投篮后出现攻板/防板/盖帽 → 最近未决投篮记失手，篮板归具名者；段末仍无得分的未决投篮全记失手 |
| 多出手 | 「近投+2」= 2 次出手（不得压缩）；随后「得分+2」只记 1 次命中 |
| 补篮 | 攻板后「得分+N」且无未决投篮 → 抢板者补篮命中（近投+1/+N分），**标黄待用户确认** |
| 前板补篮 | 字幕「A（出手+1）B（攻板+1，出手+1，得分+N）」→ **只有 B 得分，A 只记出手**（单人记分，10.17 Q19/Q20 教训） |
| 归属 | 括号内动作归括号前人名；省略名字的动作归最近具名者 |

**勾稽必查**：总得分 = 近投命中×2 + 中投命中×2 + 远投命中×3 + 罚球命中×1（+补篮推断分）；命中数必须逐条对应「得分+N」字幕。

### 4.4 填表（Excel 结构 = 10.04 最终权威版，24 列）

**模版操作红线（10.23 用户立规，违反即返工）**：模版是什么样就什么样，**只填数据**——不自己改格式、不加行删行（球员名单对了就行）、不重跑 OCR（容易把好结果做坏，用已有 OCR 结果微调）。

**剪辑记录** sheet 列序：A球员 | B开始 | C结束 | D-F近投(出/中/得) | G-I中投 | J-L远投 | M-O罚球 | **P总投出手 Q总投命中 R总投得分** | S攻板 T防板 U总篮板(公式) | V助攻 W抢断 X盖帽

- **B/C = 字幕真实完整窗口**（start_s~end_s），剪辑直接使用，不再生成衔接序列
- **★总投口径（2026-10-20 定案，含罚球）**：
  - P = `IF(COUNT(D,G,J,M)=0,"",SUM(D,G,J,M))` —— 出手**含罚球**
  - Q = `SUM(E,H,K,N)`、R = `SUM(F,I,L,O)` —— 命中/得分含罚球
  - **出手/命中/得分三者口径必须一致（全含罚球）**，否则命中率虚高（历史错误：出手漏罚球致命中率 +2.3~+5.6pp）
- **球队统计总表** sheet：A队紫底 `#F3EEF9` / B队橙底 `#F7A600`，队头行+球员行，SUMPRODUCT/SUMIF 公式
  - 球队统计页总出手=该页近投+中投+远投+罚球出手，总命中及总得分同理；命中率=总命中/总出手，零出手留空。此处按字段定义，不能直接套用剪辑记录页列字母；须读取统计页实际表头确认列位，再核验公式。
  - 数据区 `$3:$313` 等行范围、队伍成员区、SUMIF 球员名引用（必须=自身行）、分组源列，**四类引用一个都不能错**（10.19 事故：复制旧表只改人名行数，导致中投/远投错位、罚球全 0、队合计恒 0）
- **数据核对** sheet：存疑数据标黄 + 批注原始字幕 + 核对规则与结论

**异常处理**：OCR 识别≠事实。投篮类型与得分不匹配、罚球 17 次、投篮 1 次得分 8 分等异常 → **标黄留空 + 批注原始字幕，人工确认后写入，禁止编造**。

### 4.5 数据核对与定帧核验

1. 解析后把修正/存疑点汇总编号清单 **Q01~Q{n}**（文件名=问题描述）
2. 从母带按时间点抽字幕区放大图（`crop=1920:160:0:920,scale=3840:320`，-ss 定位）→ 定帧图 + `核对清单.txt` → 交用户核对
3. 用户确认后才封版，封版统计写入剪辑表
4. **★间隔帧检查**：得分事件切分后，相邻两事件之间若只有空白/脏帧且同人同分值 → 标黄人工确认（10.17 Q17/Q18 由此时发现：同一条字幕被 OCR 空白帧切成 2 个事件、脏帧残留被当成第 2 个三分）
5. **人工核对表与解析层同源，不能互当权威**：权威只有字幕原文 + 视频画面；两边数字一致也要抽 3~5 条定帧盲核

### 4.6 统计表公式体检（10.19 硬要求，交付前必跑）

只要统计表是从旧表复制/基于旧模板来的，必须：
1. 检查四类引用有无漏改（数据区行范围 / 队伍成员范围 / SUMIF 球员名引用=自身行 / 分组源列）
2. **先查「外链废表」**：公式带 `[1]` 前缀（如 `=SUMPRODUCT(COUNTIF([1]姓名库!...))`）说明统计的是**别场比赛**的数据（历史上 09.12/09.19 修正版外链到 10.04 表，全表为 0 或全错）。排查口诀：①公式有无 `[1]` 前缀 → 有则查外链目标是谁；②数据区实际行数 vs 公式行范围；③统计表列 → 剪辑记录列逐项对应；④`data_only=True` 读缓存值，全 0 即废表
3. **用 Python 按修正口径重算，逐人逐项比对 `summary_*.json`**（出手/命中/篮板/助攻/得分全比，不只比得分），并比对两队合计
   - ⚠️ `summary_*.json` 勾稽通过 ≠ 统计表对——错只在 SUMIF/SUMPRODUCT 引用上，不报错、不空值，肉眼极难发现
   - 参考脚本 `_tmp_check\verify_fix_1017.py`；体检器 `脚本库\audit\audit_stats.py`（24 列布局）
3. 汇总 summary 时命中数 = `得分 ÷ 该类单球分值`（罚球出手2得1分→命中1），**不是加出手数**；改前先用旧数据⇌旧 summary 校验规则

## 5. 第3步：构建学员集锦

### 5.1 拆分每人剪辑表（可选但推荐）
- 每学员 `02_学员集锦\{学员}\剪辑目录\{学员}剪辑表_YYYYMMDD.xlsx`：片段编号 | 球员 | 开始 | 结束 | 时长 | 各投篮(出/分) | 总投(公式) | 总得分(公式) | 攻板/防板/助攻/抢断/盖帽
- **片段编号 c00.. 与 `剪辑过程\clips\c{NN}.mp4` 一一对应（拼接顺序=时间升序）**
- **B=C（时长≤0.05s）的 0 时长占位行：不分配编号（填"—"），不参与剪辑，仅保留数据登记**

### 5.2 切段
- **`-ss` 必须在 `-i` 之前（input seek）+ `-t` 精确时长**，防掉帧
- **段 = 字幕完整窗口，不收缩**（保留完整镜头）
- 段间 0.3s 淡入淡出（不用黑场）

### 5.3 字幕残留处理（v3 口径，用户已锁定）
1. 拼接后**整体首尾各减 1s**（只去片头片尾残留，中间镜头全部保留）
2. 成片中间若仍有他人字幕残留（如陈惟勤片段14尾混入赵沐霖字幕）→ **只裁该片段对应边界 1s（EXTRA_TRIM）**，禁止全片段减秒
3. 剪辑后抽帧验证：拼接点 ±0.12s 抽底部字幕区拼图 `verify_junctions.png`，确认每帧字幕含当前学员规范姓名且动作归属正确（多人字幕不要求本人排第一）（质量底线，不可跳过）

> 字幕残留的完整原理与检测方案（MAD 切换点检测、pipeline_fix.py 全自动修复）见 `_归档\经验沉淀\字幕残留避坑指南.md`。

### 5.4 成片结构（用户 2026-10 之后锁定的目标形态）

```
每节独立成片（按赛事节次顺序剪辑）：
  封面（本节开始比分 + 球员登记照 + 身高/体重/年龄）
    → 该节全部镜头片段
    → 本节数据展示页
  …（下一节重复）…
  → 数据汇总展示页（全场）
  封底（本节/全场结束比分）

单个学员完整集锦（微电影/常规版）：
  片头 3.5s（统一模板：上=橙色"常青藤篮球训练中心" / 中=白色大字姓名 / 下="日期 训练赛集锦" / 底=透明LOGO）
    → 全部镜头（完整窗口 + 首尾减1s + 段间淡入淡出）
    → 数据卡 7s
    → 片尾
```

**数据卡规范（10.13 锁定）**：
- 投篮五格 = 总投/篮下/中投/三分/罚球，一律写 **「总X/中Y」** 格式 + 命中率 + 进度条
- 六格 = 攻板/防板/总篮板/助攻/抢断/盖帽
- 球员特点文案 = **「教练点评」**（**禁止叫"AI总结/AI点评"**），基于数据卡特征（得分/篮板/助攻/抢断/盖帽/三分/命中率）生成 1~2 句
- **全部内容 ≤ y880/1080 安全区**（防手机播放器控件遮挡）
- 封面预留球员登记照位置 + 身高/体重/年龄；数据累计后可推**个人雷达图**，配教练点评描述球员特点
- 赛季体系：2026 赛季 / 2027 新赛季，展示**月度/季度/年度数据对比 + 出赛场次**
- 数据一律读权威 json（`summary_*.json`），**禁止硬编码**

### 5.5 混音
- **背景原声 volume=0（静音只留 BGM） + BGM volume=0.85**
- `amix inputs=2:duration=first:normalize=0`（**normalize=0 必须加**，否则音量减半）
- BGM：`共享资产\bgm\bgm_full_BornFighter.m4a`（默认；试听备选 4 首）

### 5.6 产出规格（10.13 锁定：只剪手机版）
- **默认只产出并保留手机版**（1080×608 / CRF 30 / maxrate 1400k / bufsize 2800k / AAC 150k / +faststart）
- 高清版（1920×1080 / CRF 18 / preset medium）**不默认产出**，用户明确需要时按需渲染（复用手机版已验收的时间线/卡片/BGM 参数，仅换分辨率码率）
- **分发约定**：高清版数据保存电脑端 / 剪辑版（手机版）出手机端 / 统计数据进微信小程序（`D:\篮球训练馆系统\basketball-training-miniapp`）
- `剪辑成品\` 只保留最新版；**有新版本将旧版移入 `剪辑过程\_旧版本\`，验收后再按需删除**，旧版不留存

## 6. 第4步：校验（质量门，不可跳过）

| # | 检查项 | 方法 | 通过标准 |
|---|---|---|---|
| ① | 统计表公式体检 | `audit_stats.py` + Python 逐人逐项比对 `summary_*.json` | 出手/命中/得分/篮板/助攻全一致，两队合计一致 |
| ② | 总投口径 | 检查 P/T 是否含罚球、Q/U/R 是否含罚球 | 出手=近+中+远+罚；U/T == W 命中率 |
| ③ | 数据勾稽 | 总得分 = Σ(命中×分值)；命中数逐条对应得分字幕 | 全部相等 |
| ④ | 字幕残留 | `verify_junctions.png` 抽帧目检 | 每帧字幕含本人规范姓名，且动作归属正确 |
| ⑤ | 间隔帧检查 | 相邻同人同分值事件间隔帧 | 无空白/脏帧切断、无脏帧重复 |
| ⑥ | 抽查 | 每学员至少抽 2 段首尾帧 | 动作与字幕一致 |
| ⑦ | 视频规格 | ffprobe | 手机版 1080×608 / H.264 / yuv420p / 30fps / AAC 48k；PTS 间隔均匀 |

## 10. 常见坑速查

| 坑 | 正确做法 |
|---|---|
| 1fps 抽帧把字幕窗口压短 | 一律 2fps（batch_ocr2.ps1） |
| 同一条字幕被 OCR 空白帧切成 2 个事件 | 间隔帧检查；同人同分值相邻事件必查 |
| 脏帧残留当成新事件 | 相同字幕同位同内容=残留，不是新球 |
| 前板补篮被双人各记分 | 按括号归属，只有补篮人得分 |
| 复制旧表做新表统计全错 | 四类引用重排 + 统计表 vs summary 逐人逐项比对 |
| 总投出手漏罚球 | P/T = 近+中+远+罚（含罚球），与命中/得分同口径 |
| 直接用表格时间切割带残留 | 完整窗口 + 整体首尾各减1s + 仅残留片段裁边界 |
| 段尾取下一段 start | 各球员片段不连续，end 必须独立检测 |
| -ss 放 -i 后掉帧 | input seek（-ss 在 -i 前） |
| 纯色卡片无音轨 concat 失败 | 加 `-f lavfi -i anullsrc=channel_layout=stereo:sample_rate=48000` |
| concat -c copy 失败 | 所有输入同分辨率同采样率（48k stereo） |
| amix 音量减半 | 必须 `normalize=0` |
| openpyxl 覆盖表报"被另一进程使用" | **直接要求用户关闭 Excel**，不自动存副本、不绕过 |
| 长中文/引号内联 python -c | 一律写 `.py` 文件再执行 |
| 数据卡内容贴底被手机控件遮 | 全部内容 ≤ y880/1080 安全区 |
