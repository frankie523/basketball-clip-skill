# 剪辑输出规范

## 母带处理
- 拼接母带时优先 `-c copy` 流复制，不重新编码
- 万不得已必须重编码，用 CRF 18 视觉无损级别
- 不要用手机版的压缩参数去压母带！

## 手机版集锦输出参数
| 参数 | 值 |
|---|---|
| 分辨率 | 1080×608 |
| 帧率 | 30fps |
| 视频编码 | H.264 / yuv420p |
| CRF | 30（手机版压缩） |
| 音频编码 | AAC 48kHz stereo |
| 原声音量 | 0.0（静音） |
| BGM音量 | 0.85 |

## 切片段规则
- 每段 = 字幕完整窗口（不要收缩）
- 整体首尾各减1秒（防残留）
- 段间0.3秒淡入淡出
- 片段顺序按时间先后排

## 片头片尾
- 片头：深蓝紫渐变背景 + LOGO + 球员姓名 + 比赛日期
- 片尾：数据卡（投篮/篮板/助攻等统计 + 教练点评）
- 字体：微软雅黑（中文）、Arial（英文数字）

## BGM
- 默认BGM：`bgm_full_BornFighter.m4a`
- 循环覆盖全程
- 音量0.85，不要盖过任何音效（不过原声本来就是静音的）

## 文件命名
```
球员名集锦_YYYYMMDD训练赛_手机版.mp4
```
有新版本删旧版本，只留最新版。
