# 数据统计规则

## 投篮分类
| 类型 | 命中得分 | 说明 |
|---|---|---|
| 近投 | 2分 | 篮下、禁区内出手 |
| 中投 | 2分 | 三分线内、禁区外出手 |
| 远投（三分） | 3分 | 三分线外出手 |
| 罚篮 | 1分 | 罚球线出手 |

## 总投口径（最容易搞错的地方！）
**正确口径**：总投出手 = 近投出手 + 中投出手 + 远投出手 + 罚篮出手
**正确口径**：总投命中 = 近投命中 + 中投命中 + 远投命中 + 罚篮命中

⚠️ 之前的错误：出手漏了罚篮，但命中含了罚篮，导致命中率算高了
**记住：出手和命中必须同口径，要么都含罚篮、要么都不含，不能一个含一个不含**

## 篮板
- 进攻篮板（攻板）：投失后本方抢到的篮板
- 防守篮板（防板）：对方投失后本方抢到的篮板
- 总篮板 = 攻板 + 防板

## 其他数据
- 助攻：传球后队友直接得分
- 抢断：断球成功
- 盖帽：封盖对方投篮

## 比分校验
- 全场总得分 = A队得分 + B队得分
- 分段比分加起来 = 全场比分
- 和用户给的真值偏差在±3分以内可以封版，不要追求100%

## 球员数据卡（片尾用）
- 顶部：球员姓名 + 本场得分大数字
- 中间5块：投篮（出手/命中/%）、篮下、中投、三分、罚篮
- 下面6个小数据：进攻篮板、防守篮板、总篮板、助攻、抢断、盖帽
- 底部：「教练点评」（根据数据写一句特点，比如"防守端积极拼抢，篮板保护稳定"）
