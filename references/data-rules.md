## 3. 计分口径（数据核对用）

```
总得分 = 篮下命中×2 + 中投命中×2 + 三分命中×3 + 罚球命中×1
总投出手 = 篮下出手 + 中投出手 + 三分出手 + 罚球出手
总投命中 = 篮下命中 + 中投命中 + 三分命中 + 罚球命中
总投命中率 = 总投命中 / 总投出手（总投口径统一含罚球；零出手留空）
命中率 = 命中总数 / 出手总数
篮板总数 = 进攻篮板 + 防守篮板
```

**得分/命中判定规则（v5，用户 2026-10-12 锁定，取代旧的穷举拆分）**：
- **得分 = 字幕"得分+N"的 N**；其余投篮动作（近/中/远/罚）只计出手次数，不直接出分
- **命中**：投篮子句后**紧邻**"得分+N"（中间无篮板/盖帽/人名切换）→ 该次投篮命中，得分 N 归该投篮者
- **失手**：投篮子句后出现 攻板/防板/盖帽 → 最近一次未决投篮失手，篮板归该子句具名者；段落结束仍无得分的未决投篮全部记失手
- **多出手**：字幕"近投+2"=2 次出手（不得按投票/众数压缩）；命中次数=随后"得分+N"的 1 次，其余记失手
- **补篮推断**：攻板后出现"得分+N"且无未决投篮 → 按抢板者补篮命中计（近投 1 中/+N 分），标黄待人工确认
- **同句攻板+防板并存**：如"甲近投+1，乙攻板+1，丙防板+1"→ 默认漏了补篮出手"近投+1"（乙补篮再投不中→丙防板）；**先与用户确认再写入**（f054/f099 已确认）
- **归属**：人名后动作归该人；新名字出现后动作归新名；省略名字的动作归最近具名者
- 旧"穷举拆分"规则仅适用于字幕完全不给得分、只给总分的旧素材，新素材一律按上述逐球判定

**自查规则（违反即为数据错误）**：
- 单次篮下/中投得分必须是 0 或 2；三分 0 或 3；罚球 0 或 1
- 得分与命中次数必须勾稽（例：得分 20 = 篮下 8×2 + 中投 2×2 + 三分 0 + 罚球 0）
- 出手次数 ≥ 命中次数；篮板、助攻等非负
- 全场得分榜与每人统计总表必须一致
- 同一字幕不得被切段重复计数（防 OCR 动作漂移；判定见第 4 节）

## 4. 剪辑时间口径

- 表格"开始/结束时间"（B/C 列）**= 字幕真实完整窗口**（start_s~end_s，剪辑直接使用；同字幕多人拆行时 B/C 完全一致）
- **字幕窗口 = 字幕完整显示区间**（首帧~末帧，2fps 下精度 0.5s），不是单帧——防止把 0~6s 的字幕压成 1s
- **防同字幕切段**：连续帧合并条件 = 动作种类子集 **或** 文本相似度 ≥0.85（OCR 动作归属漂移/漏读时靠文本兜底，实测彭天乐远投由虚高 8 修正为真实 6）
- 集锦切割使用**源视频真实时间**（= 表格 B/C，同一来源 `_数据源\03_解析\parsed_1004_v2.json`）
- 切割窗口（v3 口径）：**段 = 字幕完整窗口，不收缩**（保留完整镜头）；拼接后**整体首尾各减 1s**（防首尾残留，中间镜头全部保留），段间 0.3s 淡入淡出（另见《经验沉淀\字幕残留避坑指南.md》）
