# OCR识别经验

## 开工前必做
1. **先抽3段真实字幕看格式**，不要想当然！
2. 确认格式后再写正则表达式
3. 拿前10条事件测试，识别正确再批量跑

## 常见字幕格式（都见过）
- 格式A：`彭天乐（近投+1，得分+2）` —— 全在括号里
- 格式B：`彭天乐（近投+1），得分+2` —— 部分在括号外
- 格式C：`彭天乐（近投+1，攻板+1），近投+1，得分+2` —— 括号内外都有

## 容易识别错的地方
1. **脏帧残留**：字幕刚消失时的残影，会被当成新的一条
   - 解决：看连续窗口，间隔<0.5秒的合并成一条
2. **同一条拆成两条**：字幕中间有一帧空白，被识别成两个事件
   - 解决：时间间隔<0.3秒且球员相同的，合并
3. **名字识别错**：球员名字相近，比如"熊泽海"识别成"熊译氵"
   - 解决：建一个名字对照表，模糊匹配修正
4. **补篮归属**：字幕写"张三近投+1，李四攻板+1，近投+1，得分+2"
   - 解决：得分归给最后投进的那个人，不是最先投篮的

## 自检方法
1. 先跑一遍，统计总比分
2. 和用户给的真值比分比对，差超过5分就有问题
3. 差得越多说明重复统计越严重
4. 对称偏差（A多3分、B多3分）大概率是重复记录

## 不要做的事
- 不要跳过人工定帧核验，直接信OCR结果
- 不要从15分钟跳到20分钟，只做前半段就以为做完了
- 不要改了OCR逻辑就重跑一遍覆盖之前的好结果
