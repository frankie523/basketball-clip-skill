# 常青藤篮球集锦剪辑 — 字幕残留避坑指南

> 现行说明（2026-10-21）：以《通用剪辑规范》v2.1为准。保留完整窗口，仅拼接主体整体首尾各减1秒；多人字幕验证本人姓名及动作归属，不要求本人排第一；默认仅手机版，原声静音。下文旧方案保留作复盘。

## 问题根因

球员集锦的片段起止时间来自**比赛剪辑表（OCR识别）**，表中记录的"开始时间"通常是**动作发生时刻**，而视频底部字幕的切换比动作时刻**晚 0.2~0.8 秒**（字幕需要反应时间，切换动画约0.2-0.3s完成）。

直接按表格时间切割，会导致**每段开头带入上一名球员的底部字幕约0.5秒**，即"字幕残留"。

---

## 三种避免方式（推荐组合使用）

### 方式一：表格填写阶段加偏移（最省力，推荐日常使用）

在填写比赛剪辑表时，**开始时间统一往后延 0.3~0.5 秒**：

| 原表开始时间 | 建议填写时间 | 说明 |
|---|---|---|
| 00:17 | 00:17.5 | 字幕约0.5s后完全切换 |
| 00:51 | 00:51.5 | 同理 |

- **操作方法**：看到某个球员的动作/字幕出现时，**等字幕完全显示后再记时间**，不要在动作刚发生时就按表。
- **结束时间**不需要调整，保持原时刻即可（片尾带入下一人字幕不影响，因为下一段会切掉）。
- **优点**：从源头解决，后续剪辑无需额外处理。
- **缺点**：需要记录者养成习惯，个别片段可能仍有0.1-0.2s误差。

### 方式一B：完整镜头 + 集锦整体首尾各减1秒（10.4 最终标准，v3）

> **口径沿革**：曾用"每段 [start+1, end-1]"（v2，最干净但把镜头裁短）→ 用户反馈镜头不完整 → 2026-10 敲定 **v3：段 = 字幕完整窗口（不收缩），拼接后整段集锦整体首尾各减 1s**（只去片头片尾残留，中间镜头全部保留）。

| 字幕显示区间 | 段窗口（完整） | 拼接后处理 |
|---|---|---|
| 0.0~6.0s | 0.0~6.0s（不收缩） | 集锦开头减 1s（首段淡入残留区） |
| 89.0~93.0s | 89.0~93.0s（不收缩） | 集锦结尾减 1s（末段淡出残留区） |

- **已实测验证（10.4 陈惟勤 v3，17段/108s）**：首片段开头字幕为该学员自己的字幕（陈惟勤助攻+1…），无残留；108s 比 v2 的 76s 多 32s（镜头全部保留）。
- 段间 0.3s 淡入淡出转场；短段无需特殊保护（不再收缩窗口）。
- **优点**：镜头完整 + 残留可控，兼顾用户最在意的两点。
- **实现**：脚本库 `compose\batch_build_1004.py`（v3）已内置该策略；表格 B/C 列 = 字幕完整窗口。

### 方式二：剪辑前自动检测字幕切换点（最精准，推荐批量生产）

使用已验证的检测脚本 `detect_subtitle_switch2.py` 或通用流水线 `pipeline_fix.py`：

1. 脚本对每段起止附近逐帧分析底部字幕区（crop=1920:200:0:880）的灰度帧差（MAD），找到字幕实际切换的帧。
2. 自动修正规则：
   - **段首**：取检测到的切换点 + 0.2s 余量（确保字幕已完全切换）
   - **段尾**：仅当切换点在 [原end-0.7, 原end] 范围内才采纳，否则保持原 end
3. 按修正后的时间重剪集锦。

```bash
# 单球员全自动修复（检测+修正+重剪+验证拼图）
python pipeline_fix.py <球员名> <0912|0919>
```

### 方式三：剪辑后验证（必须做，质量底线）

重剪后对**每个段间切换点**抽帧验证：
- 段首取拼接点 +0.12s，段尾取拼接点 -0.12s
- 裁剪底部字幕区（1920x200）拼图，肉眼确认每帧字幕以当前球员名字开头
- 流水线自动生成 `verify_junctions.png`

```bash
# 手动修正后仅重剪（不需重新检测）
python pipeline_rebuild_only.py <球员名> <0912|0919>
```

## 推荐工作流（未来比赛）

```
1. 录制比赛 → 2. 填写剪辑表（B/C = 字幕完整显示区间，2fps OCR 定位）
   → 3. 段 = 字幕完整窗口拼接；集锦整体首尾各减1s（方式一B v3，已内置脚本）
   → 4. 抽帧验证首尾/段间无残留（方式三，质量底线）
   → 5. 生成卡片 + 合成精编版（batch_build_1004.py / pipeline_cards.py + pipeline_compose.py）
```

**核心原则**：表格时间是"参考"，视频字幕切换点才是"事实"。永远以视频实际帧为准。

---

## 常见误区

| 误区 | 正确做法 |
|---|---|
| 直接用表格B/C列时间切割 | 用 v3 数据的 start_s/end_s，且经过字幕切换检测修正 |
| 段尾取下一段的 start 作为 end | ❌ 各球员片段在源视频中不连续，段间有他人内容，end 必须独立检测 |
| 只抽查几名球员 | 所有球员都可能有残留，必须全量检测 |
| 检测脚本结果直接用不验证 | 脚本对浅色地板白字不敏感，个别段会漏检，必须看验证拼图 |
| 用 -ss 在 -i 之后（output seek） | 用 -ss 在 -i 之前（input seek）+ -t 精确时长，避免掉帧 |
