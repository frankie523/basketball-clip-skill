## 二、09.12 / 09.19 修正版为什么是废表

### 2.1 统计表公式全部是「外部工作簿链接」

公式长这样（注意 `[1]` 前缀）：

```
=SUMPRODUCT(COUNTIF([1]姓名库!$A$3:$A$254,[1]剪辑记录!$A$2:$A$253),[1]剪辑记录!H$2:H$253)
```

解包 xlsx 看 `xl/externalLinks/_rels/externalLink1.xml.rels`，两张表的外链目标**都是**：

```
Target="\视频剪辑\01_比赛\2026.10.04训练赛\01_比赛剪辑表\比赛剪辑表_20261004训练.xlsx"
```

**即：09.12 / 09.19 的统计总表，统计的是 10.04 那场比赛的数据。**

而且该路径**缺盘符**（`\视频剪辑\...` 而非 `D:\视频剪辑\...`），链接实际已断——
用 `data_only=True` 读缓存值，**A队/B队全部为 0**，即用户在表里看到的是一片 0。

### 2.2 列映射全错（即使在 10.04 表内部也对不上）

08/09 的旧表是 18 列布局（近投/得分/中投/得分…没有「出手/命中」子列），
但被引用的 10.04 表是 24 列布局（近投出手/命中/得分/中投出手/…）。逐项对下来：

| 统计表列 | 含义 | 实际引用 | 在10.04表里其实是 | 判 |
|---|---|---|---|---|
| D | 近投 | H | 中投命中 | ✗ |
| E | 得分 | I | 中投得分 | ✗ |
| G | 中投 | J | 远投出手 | ✗ |
| H | 得分 | K | 远投命中 | ✗ |
| J | 远投 | L | 远投得分 | ✗ |
| K | 得分 | M | 罚球出手 | ✗ |
| M | 罚篮 | N | 罚球命中 | ✗ |
| N | 得分 | O | 罚球得分 | ✗ |
| Q | 总投得分 | Q | 总投命中 | ✗ |
| S | 攻板 | R | 总投得分 | ✗ |
| T | 防板 | S | 攻板 | ✗ |
| V | 助攻 | T | 防板 | ✗ |
| W | 抢断 | U | 总篮板 | ✗ |
| X | 盖帽 | V | 助攻 | ✗ |

### 2.3 行范围也错

引用 `$2:$253`，而 10.04 数据区是 **3~275**：
漏掉 254~275 共 22 行，且第 2 行是子表头行（被当成数据）。

### 2.4 「总时长 C」算的是中投出手 − 近投得分

```
C = SUMPRODUCT(...,[1]剪辑记录!$G$2:$G$253) - SUMPRODUCT(...,[1]剪辑记录!$F$2:$F$253)
```
在 10.04 布局里 F=**近投得分**、G=**中投出手**，根本不是时间列（时间列是 B/C）。

## 四、体检器（可复用，已归档脚本库）

`00_流程与规范\脚本库\audit\audit_stats.py` —— 自动解析《球队统计总表》里
SUMIF / SUMPRODUCT 的**引用列、行范围、球员名单元格、成员名单范围**，
与理论映射逐项比对，输出所有不一致。

```
python audit_stats.py                        # 体检 4 张默认表
python audit_stats.py <xlsx路径> ...         # 指定文件
```

**已知局限（重要）**：它只适用于 **24 列新布局**。
对 18/20 列的旧布局（09.12/09.19 修正版）会**假阴性报「全部正确」**
—— 因为正则匹配不到就跳过。所以旧布局必须单独用
`audit_old.py` 或直接解包看 `externalLinks` 来查。

**通用排查口诀**：
1. 公式里有没有 `[1]` 前缀 → 有就是外链，先查外链目标是谁
2. 数据区实际到第几行 → 对照公式里的行范围
3. 统计表某列 → 应该在《剪辑记录》里对应哪一列 → 逐项数一遍
4. 用 `data_only=True` 读缓存值，全 0 或明显不合理就是有问题
